# HRDL — KOVO Hrdlička

Prémiový web zakázkové kovovýroby. Pavel Hrdlička, Nová Ves nad Nisou.

**Live / Vercel:** napojte tento repositář na [Vercel](https://vercel.com) (Framework Preset: Vite / Other, build `npm run build`, výstup řeší Nitro `vercel` preset).

## Obsah

- Úvod, realizace, služby, o řemesle, kontakt
- Čeština, Space Grotesk, černobílý minimální design
- JSON-LD LocalBusiness, SEO meta, bezpečnostní hlavičky
- Formulář otevírá e-mail (nic se neukládá na server)

## Lokálně

```bash
npm install
npm run dev
```
